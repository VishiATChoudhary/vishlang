# VishLang v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans, inline. TDD per task.

**Goal:** profiles under ~/.vishlang, Codex history source, generic skill for Claude Code + Codex,
`vishlang install`, `install.sh`, marketing README, public GitHub repo.

**Spec:** docs/superpowers/specs/2026-10-31-vishlang-v1-profiles-install-design.md

## Global Constraints
- No em dashes anywhere. Python 3.12, stdlib first. Tests must not touch ~/.vishlang or ~/.codex:
  fixtures set VISHLANG_HOME and source paths explicitly.

## Tasks

### Task 1: profile paths and config
- `vishlang/paths.py`: `home() -> Path` (env VISHLANG_HOME or ~/.vishlang), `profile_dir(name) -> Path`,
  `Profile` dataclass with `name, dir, config, raw, data, pairs, adapters, latest` and
  `Profile.load(name)` reading `<dir>/profile.toml` through `load_config` (missing file = DEFAULTS).
- `load_config(path)` tolerates a missing file.
- Tests: `tests/test_paths.py` with monkeypatched VISHLANG_HOME.

### Task 2: CLI on profiles
- global `--profile` (default env VISHLANG_PROFILE or "default"); subcommands drop `--raw/--out/--data/--adapters/--corpus/--holdout` defaults in favour of the profile; keep flags as overrides.
- `vishlang init NAME [--name --email]` writes profile.toml and creates raw/.
- `vishlang profiles` lists name, corpus size, trained yes/no.
- Tests: `tests/test_cli_profiles.py` (init writes toml; profiles lists; rewrite uses profile adapter path via FakeLM capture).

### Task 3: Codex history source
- `parse_codex(path, max_words=200)` in ingest.py: response_item/message/role user/input_text; same harness filters; extra prefixes `# AGENTS.md`, `<environment_context>`, `<send_user_message`.
- `[sources.codex] path="~/.codex/sessions"` in DEFAULTS; ingest_dir walks it like claude.
- Fixture `tests/fixtures/codex/rollout.jsonl`; test file `tests/test_ingest_codex.py`. Existing cfg fixtures set codex path "".

### Task 4: multi-profile serve
- `serve.py`: `ProfileRouter(load_lm: Callable[[str], LM|None])` with `rewrite(text, profile)`; cache per profile; unknown/untrained profile returns error string listing trained profiles.
- `make_server(router)`; MCP tool `rewrite(text: str, profile: str = "default")`.
- `mcp_add_command()` returns `claude mcp add -s user vishlang -- vishlang serve` (no --directory).
- Tests: `tests/test_serve.py` additions with FakeLM.

### Task 5: install command + skill
- `skills/vishlang/SKILL.md` generic; packaged via hatch force-include to `vishlang/skill/SKILL.md`.
- `vishlang/install.py`: `install(home_claude, home_agents, run)` copies skill dir, registers MCP for each CLI found (`shutil.which`), `claude mcp remove` first to be idempotent; returns list of actions.
- CLI `vishlang install`. Tests with tmp dirs and a recording `run`.

### Task 6: install.sh, README, publish
- `install.sh`: uv present or install; `uv tool install --force git+https://github.com/VishiATChoudhary/vishlang`; `vishlang install`; next-steps text.
- README rewritten with the pitch. Remove vishlang.toml from repo; migrate local state to ~/.vishlang/profiles/default.
- `gh repo create VishiATChoudhary/vishlang --public --source . --push`.
